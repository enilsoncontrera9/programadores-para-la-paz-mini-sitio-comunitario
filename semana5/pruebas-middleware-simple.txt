5. ¿Qué hace el middleware simple?

Respuesta: Funciona como un filtro o guardián en el servidor. Se interpone entre la petición que hace el usuario 
y la ruta final

6. ¿Por qué este middleware no debe confundirse con seguridad real?

7. ¿Qué aprendiste sobre rutas públicas y rutas protegidas?

Respuesta: Aprendí que las rutas públicas están abiertas para cualquiera, mientras que las protegidas necesitan 
una capa de verificación previa para resguardar la información, ademas entendí que el control de acceso se maneja 
desde el backend mediante tokens y que el frontend solo se encarga de reaccionar visualmente a lo que el servidor 
autorice.
