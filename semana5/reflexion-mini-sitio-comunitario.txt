Escribe una reflexión de 8 a 10 líneas respondiendo:

¿Por qué un mini-sitio que consume una API puede ayudar a una comunidad a difundir información de forma responsable, organizada y verificable?

En tu respuesta menciona al menos cinco de estas ideas:

- proyecto único en GitHub
- rama main
- rama personal
- git pull origin main
- fast-forward
- async
- await
- fetch
- API
- JSON
- difusión responsable
- planificación del calendario editorial
- calendario editorial
- revisión de fuentes
- consistencia comunicativa
- moderación editorial básica
- lenguaje responsable y no estigmatizante
- participación ciudadana
- cultura de paz

Respuesta: Un mini-sitio que consume una API ayuda a la comunidad porque permite mostrar información organizada y 
fácil de consultar mediante datos en formato JSON. Además, usando fetch, async y await el sitio puede cargar mensajes 
y calendarios de manera más rápida y ordenada. La API también ayuda a mantener una difusión responsable porque la 
información puede revisarse antes de publicarse. El calendario editorial permite planificar las publicaciones y 
mantener una consistencia comunicativa en todos los mensajes. También es importante la revisión de fuentes para 
evitar desinformación y compartir contenido verificable. En GitHub, trabajar con un proyecto único ayuda a mantener 
mejor organizado el trabajo del equipo. La rama main guarda la versión principal, mientras cada estudiante trabaja 
en su rama personal para evitar errores. El comando git pull origin main permite actualizar los cambios más recientes 
y el fast-forward ayuda a integrar cambios de forma más sencilla. Todo esto fortalece la participación ciudadana, el 
lenguaje responsable y la cultura de paz en los espacios digitales.
