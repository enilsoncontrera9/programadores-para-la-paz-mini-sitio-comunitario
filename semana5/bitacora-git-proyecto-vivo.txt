4. Comando usado para clonar el repositorio:

Respuesta: git clone URL_DEL_FORK

5. Comando usado para entrar a la carpeta del proyecto:

Respuesta: cd nombre-del-proyecto

6. Comando usado para crear tu rama personal:

Respuesta: git checkout -b enilson_contreras

7. Comando usado para verificar la rama actual:

Respuesta: git branch

8. Comando que se usará desde la Clase 22 para traer cambios de main:

Respuesta: git pull origin main

9. Explica con tus palabras qué significa fast-forward:

Respuesta: Significa que Git puede avanzar directamente a los cambios nuevos porque no existen conflictos entre las ramas.

10. ¿Por qué no se debe trabajar directamente en main?

Respuesta: Porque la rama main es la principal del proyecto y si alguien comete un error puede afectar el trabajo de 
todo el equipo, ademas, se debe hacer una copia del repositorio en nuestra propia cuenta de GitHub usando el botón Fork, ya que 
si se clona directamente el repositorio del docente, GitHub no dejará subir cambios con git push, ya que no se tienen 
permisos sobre el repositorio original.

Respuesta: git status

12. Comando usado para agregar cambios:

Respuesta: git add .

13. Comando usado para crear commit:

Respuesta: git commit -m "+ mensaje de commit"

14. Comando usado para publicar tu rama:
